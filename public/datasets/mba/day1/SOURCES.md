# Day 1 — real datasets (sources)

All files are real public data (not synthetic). Some files are **row extracts** of the original for Excel-friendly size; rows are not invented.

| File | Description | Source |
|------|-------------|--------|
| `sample-superstore.xlsx` | Tableau Sample Superstore (Orders, Returns, People) | Classic Sample - Superstore workbook |
| `online-retail-uk.csv` | First 20,000 United Kingdom rows from UCI Online Retail | https://archive.ics.uci.edu/dataset/352/online+retail |
| `telco-customer-churn.csv` | IBM Telco Customer Churn (full) | https://github.com/IBM/telco-customer-churn-on-icp4d |
| `hr-employee-attrition.csv` | IBM HR Employee Attrition (full) | IBM employee attrition sample (AIF360 / public CSV) |
| `hotel-bookings.csv` | First 20,000 rows of hotel booking demand | TidyTuesday hotels (Antonio et al. hotel booking demand) |
